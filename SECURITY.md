# Security Policy

## Supported Versions

Only the latest release of Agy Helper on the `main` branch receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Agy Helper team takes security seriously, especially given our focus on vulnerable computer users, families, and seniors.

If you discover a security vulnerability or bypass in the `safety_engine.py` guardrails:

1. **Do NOT open a public issue** on GitHub.
2. Please submit a private vulnerability report via **GitHub Security Advisories** on this repository (click the **Security** tab, then **Report a vulnerability**).
3. Alternatively, report it privately to our security team at `security@agy-helper.open`.

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept shell string that bypasses the safety engine.
- Proposed remediation or patch, if available.

### Our Commitment:
- We acknowledge receipt of security reports within 48 hours.
- We will provide a regular status update on remediation progress.
- Once fixed, we will publicly credit the reporter (unless anonymity is preferred) and release a patched version immediately.
